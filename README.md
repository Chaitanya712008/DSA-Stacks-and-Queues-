# C++ Stacks and Queues Project

This repository contains lightweight and modular implementations of core linear data structures using C++. Developed for the CCE-2 assessment with a focus on memory management and version control.

---

### Project Blueprint

* stack_using_array.cpp -> Array-backed stack implementation
* stack_using_linked_list.cpp -> Pointer-based dynamic stack allocation
* queue_using_array.cpp -> Linear queue using static arrays
* queue_using_linkedlist.cpp -> Unbounded queue using custom nodes

---

### How to Build and Run

To compile and execute any module, run the following commands in your terminal:

g++ stack_using_array.cpp -o stack
./stack

g++ queue_using_array.cpp -o queue
./queue

---

### Environment Notes
* Requirements: GCC / G++ Compiler
* Standard: C++11 or higher
